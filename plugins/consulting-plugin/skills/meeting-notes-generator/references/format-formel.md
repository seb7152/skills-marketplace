# Format Formel - Compte Rendu de Réunion Officiel

## Usage
Comptes rendus destinés à l'archivage, à la signature, ou à une diffusion officielle auprès de tiers externes. Ton neutre, exhaustif, structuré pour la clarté juridique et administrative.

## Structure obligatoire

### En-tête
```
COMPTE RENDU DE RÉUNION
─────────────────────────────────────────

Titre de la réunion : [Exact title]
Date : [DD/MM/YYYY]
Horaire : [HH:MM - HH:MM]
Durée : [X min]
Lieu/Format : [Physique / Visio / Hybride + localisation]
```

### Participants
```
PARTICIPANTS
─────────────
• Prénom Nom (Rôle / Entreprise)
• Prénom Nom (Rôle / Entreprise)
…

Absents excusés :
• [si applicable]
```

### Ordre du jour
```
ORDRE DU JOUR
──────────────
1. [Sujet 1]
2. [Sujet 2]
3. [Sujet 3]
…
```

### Corps (par point d'ordre du jour)
```
## Point 1 : [Titre du sujet]

**Contexte** : [Contexte court, factuel]

**Discussion** : 
[Synthèse objectif de ce qui a été dit. Citer les échanges principaux, les avis divergents le cas échéant, sans jugement.]

**Décision / Conclusion** :
[Ce qu'il en résulte : décision prise, consensus, ou décision en attente.]

### Point 2 : ...
```

### Actions
```
ACTIONS EN RÉSULTAT
────────────────────
| N° | Action | Responsable | Deadline |
|-----|--------|-------------|----------|
| 1 | [Libellé clair] | [Nom] | [DD/MM/YYYY] |
| 2 | ... | ... | ... |
```

### Prochaine réunion
```
PROCHAINE RÉUNION
──────────────────
Date : [DD/MM/YYYY]
Horaire : [HH:MM]
Sujets prévisibles : [si connus]
```

### Approbation
```
APPROBATION
────────────
Rédacteur : ________________________     Date : ___________
Approuvé par : ______________________    Date : ___________
```

## Directives de rédaction

- **Ton** : Neutre, professionnel, documentaire
- **Temps** : Passé composé ou présent (descriptions factuelles)
- **Précision** : Inclure les chiffres, dates, noms propres complets
- **Exhaustivité** : Chaque point traité doit être couvert, même brièvement
- **Trace écrite** : Convient à une archivage légal et à la communication interne/externe
- **Longueur** : 2–5 pages selon la complexité
- **Aucun emoji** : Pas de symboles graphiques ni d'emojis dans le document

## Points de contrôle

✓ Tous les participants cités correctement  
✓ Décisions explicites identifiées et formulées clairement  
✓ Actions assignées à un responsable nommé et une deadline  
✓ Pas d'avis personnel ou d'interprétations de la part du rédacteur  
✓ Jargon technique expliqué pour les tiers externes  
✓ Références annexes (documents, liens) inclus si applicables
